**Last updated:** November 6, 2026

my-feed is a personal script run by Clark for his own use. It is not offered to the public.

## What it accesses
my-feed signs in to Clark's own YouTube account through Google's OAuth. It reads the channels he subscribes to and their recent uploads, and it adds videos to his own playlists.

## What it stores
It does not collect, store, sell or share anyone's personal information. The only credential it keeps is the sign-in token for Clark's account, stored as an encrypted secret in a private GitHub repository.

## Google user data
my-feed's use of information received from Google APIs follows the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access
Access can be removed at any time from [Google Account → Third-party connections](https://myaccount.google.com/connections).
